# 생활 작업 실행 순서 점검

## 발견한 문제와 수정 기준

| 지점 | 기존 비효율/오류 | 수정 기준 |
| --- | --- | --- |
| 시작 조건 | 전체 재료를 모을 때까지 가공 시설이 쉼 | 보유 재료로 가능한 가공부터 등록 |
| 목표 처리 | 한 품목의 재귀 처리가 끝나야 다음 품목 진행 | 전체 목표와 하위 재료를 하나의 계획으로 관리 |
| 시설 활용 | 다른 시설의 실행 가능한 가공도 기다림 | 현재 시설을 채운 뒤 다른 시설도 가동 |
| 대기열 | 현재 레시피 위주 계산 | 시설 전체의 진행·대기·완료 미수령 일감을 모두 점유로 계산 |
| 재료 합산 | 공통 재료/최종 보유분/등록 일감 누락 가능 | 전체 수요 합산, 보유량·등록 산출량 차감 후 생산 단위 올림 |
| 채집 | 가공 종료 후에도 전체 채집 목표까지 계속 | 채집 중 시설 완료 확인, 중지 응답 후 수령으로 전환 |
| 첫 채집 | 재료가 없으면 전체량을 먼저 채집 | 시설을 돌릴 다음 대기열 분량부터 확보 |
| 제작 | 제작 횟수를 항상 1로 요청 | 보유 재료와 남은 목표에 맞춰 묶음 제작, CLI 최대 횟수 반영 |
| 재개 | 과거 부족분이 남아 중복 채집 가능 | 매 행동 후와 재개 시 실제 재고·일감으로 재계산 |
| 보관함 | 재료와 최종 목표의 재고 기준 혼동 | 보관함은 재료에만 반영, 최종 목표는 가방에서 검증 |
| 레시피 | 공개 표를 최신 게임 수치로 오인 | 현재 CLI 생산량/확인된 재료 우선, 불완전한 표는 묶음 제작 제한 |
| 품목명 | 모든 괄호를 제거해 색상·등급을 합침 | 확인된 철괴 원료 경로만 동일 산출물로 처리 |
| 조회/정지 | 중복 조회, 낚시/중지 경쟁 상태 | 판단마다 재고·대기열 스냅샷, 진행 없는 반복 감지 |
| 첫 대기열 재료 | 원재료 하나의 전체량부터 채집해 시작 지연 | 다음 7칸에 부족한 다른 원재료를 먼저 확보 |
| 수령 동선 | 여러 시설을 수령한 뒤 다시 채우러 왕복 | 수령한 시설부터 재등록하고 다른 시설로 이동 |
| 불필요한 수령 | 이미 충족한 목표의 기존 일감까지 수령 | 남은 수요 또는 시설 슬롯 확보에 필요한 일감만 방문 |

## 실행 원칙

완료된 시설을 수령하고, 보유 재료로 가능한 가공 대기열을 채웁니다. 다른 시설도 실행할 수 있으면 먼저 가동하고, 필요한 제작을 묶음 실행합니다. 그 뒤 부족 재료를 채집합니다. 채집 중 시설의 현재 일감이 모두 끝나면 채집 중지를 요청하고 응답을 확인한 뒤 수령합니다. 아직 실행할 일이 없을 때만 남은 시간을 조회하며 기다립니다.

가공 중인 시설의 일부 일감만 완료된 경우에는 일괄 수령을 기다립니다. 사용자가 직접 등록한 다른 일감도 슬롯 점유에 포함합니다. CLI는 시설당 한 번에 한 일감만 등록하며 각 실행 요청에 날개 비용이 있으므로, 프로그램에서 그 API 비용 자체를 없앨 수는 없습니다.

레시피 전체가 없는 품목은 CLI에서 확인된 재료만 계획할 수 있습니다. 새 부족 재료가 드러나면 계획을 확장합니다. 구매·교환 등 확보 경로가 없는 부족 재료와 레벨 제한은 발견 즉시 사유를 표시합니다. 게임 장비는 보유량 조회가 지원되지 않아 자동 완주 검증 대상에서 제외합니다.

검증은 가상 CLI의 재고 소비·시설별 시간 진행·대기열·채집 중지와 실제 CLI의 읽기 전용 조회로 구분합니다. 실제 게임에서 재화를 소비하는 완주 결과는 별도입니다.

## 검증 결과 (2026-09-25)

- 전체 자동 테스트 50개 통과, PySide6 화면 초기화 통과.
- 철 광석 80개 → 첫 7회 가공 등록 후 채집, 추가 광석 합계 260개, 철괴 102개.
- 철괴·강철괴 각각 100개 → 목표 입력 순서와 무관하게 철괴 68회·강철괴 34회 생산, 최종 각각 102개.
- 기존 가공 7회가 있으면 해당 7회를 중복 등록하거나 그 재료를 다시 확보하지 않음.
- 다른 시설 가동, 수령한 시설 우선 재등록, 다른 품목의 슬롯 점유, 공통 재료 합산, 보관함 재료, 제작 횟수 상한, 부분 성공 후 화면 차단 재개, 낚시·채집 중지 경쟁 상태 검증.
- 실제 CLI 읽기 전용 계획 확인: 조회 당시 철괴 32개·철 광석 288개·등록 일감 없음 → 철괴 23회 가공 필요, 추가 채집 없음, 즉시 가공 가능한 것으로 계산.
- 실제 게임 생산·채집 명령은 실행하지 않음. 공개 표에서 아직 확인되지 않은 재료와 장비 보유량 조회 제한은 README에 명시.
