# Mocro — 모비 통합 매크로 (마비노기 모바일 생활·던전 도우미)

`모비 통합 매크로.exe` 하나에 두 가지 기능이 들어 있습니다.

- **생활**: 채집·가공·제작 목표를 입력하면 가방·보관함 재료와 시설 대기열을 확인해 작업 순서를 계획하고 진행합니다. 게임 조작에는 `MabinogiMobile_CLI.exe`만 쓰고 화면 클릭은 하지 않습니다.
- **던전**: 은동전으로 **룬다 일반 1-1**, 마족 공물로 **페카 고분 심층 2-1**을 반복합니다. 재화를 다 쓰면 가방을 정리하고 다른 100레벨 캐릭터로 바꿔 계속합니다. CLI에 던전 명령이 없어서 상태 확인은 CLI로, 입장·이동·정리는 화면 인식과 클릭으로 합니다.

> 개인 프로젝트입니다. 게임 업데이트로 화면이나 CLI 동작이 바뀌면 동작하지 않을 수 있습니다. 처음에는 짧게 시험하고, 게임 이용 정책을 확인한 뒤 사용하세요.

## 설치

1. [Releases](https://github.com/yuudong123/Mocro/releases)에서 `Mobi-Integrated-Macro-x.y.z.zip`을 받아 압축을 풉니다.
2. `모비 통합 매크로\모비 통합 매크로.exe`를 실행합니다. 관리자 권한 확인 창이 뜨면 **예**를 누릅니다(게임이 관리자 권한으로 돌아서 화면 인식·입력에 관리자 권한이 필요합니다).
3. 폴더째 원하는 곳에 두고 쓰세요. 설정·로그·캐릭터 기록은 exe 옆 `data` 폴더에 저장됩니다. 새 버전으로 바꿀 때는 이 `data` 폴더를 새 폴더로 옮기면 그대로 이어서 씁니다.

Python이나 추가 설치는 필요 없습니다. 게임 CLI 기본 위치는 `C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe`이고, 다르면 「생활」 탭의 **설정**에서 바꿉니다. 키보드 감지(F12)와 화면 캡처 때문에 백신이 오탐할 수 있습니다.

## 생활 탭 사용법

1. 게임에 캐릭터로 접속합니다.
2. 검색이나 시설별 목록에서 목표 품목을 골라 **담기**합니다. `철괴 100, 강철괴 100`처럼 텍스트로 넣어도 됩니다.
3. **가방에 있는 수량 포함**을 켜면 최종 보유량, 끄면 지금 수량에 더해 추가로 확보할 양입니다.
4. 필요하면 **설정**에서 원료 경로가 여러 개인 레시피(철괴 등)의 기본값을 정합니다. 정령의 날개 사용 한도와 화면이 막혔을 때의 복구 방식도 고를 수 있습니다.
5. **시작 / 재개**를 누릅니다. 자주 쓰는 목표는 프리셋으로 저장하면 버튼 한 번으로 시작합니다.

가진 재료로 가공을 먼저 등록하고, 기다리는 동안 부족한 재료를 채집하거나 제작합니다. 가공 시설은 최대 7칸 대기열을 쓰고, 가방 무게가 90% 이상이면 채집을 멈추고 가공·제작·수령만 합니다. 중지 후 다시 시작하면 현재 재고와 대기열을 새로 읽고 남은 작업부터 이어 갑니다. 이미 등록한 가공은 중지해도 게임에서 계속 진행됩니다.

## 던전 탭 사용법

1. 게임 창을 **800×600**으로 맞추고 100레벨 캐릭터로 접속합니다.
2. 「던전」 탭에서 옵션을 고릅니다.
   - **재화를 다 쓰면 다른 100레벨 캐릭터로 바꾸기**
   - **캐릭터를 바꾸기 전 가방 정리**(상자 열기·장비·룬 분해)
   - **정령의 날개 사용**: 다른 지역으로 갈 때
   - **던전 밖에서 시작할 던전**: 자동이면 캐릭터가 있는 던전이나 갈 수 있는 던전부터
   - **클리어 횟수 제한**: 0이면 재화를 다 쓸 때까지
3. 처음에는 **상태 확인**으로 조작 없이 인식이 되는지 보고, 횟수 제한을 2 정도로 걸어 시험해 보세요.
4. **시작**을 누릅니다. 클릭하는 동안 게임 창이 앞으로 나오고 마우스가 움직입니다. **중지** 버튼이나 **F12**로 멈춥니다.

탭 아래에 실행 기록과 캐릭터별 은동전·마족 공물(마지막 기록 + 충전 추정)이 표시됩니다. 문제가 생겨 멈추면 그때 화면이 `data\dungeon\logs\`에 저장됩니다.

### 던전에서 하는 일

- 캐릭터가 있는 던전(안이나 입구)부터 돌고, 그 재화가 떨어지면 다른 던전으로 이동합니다. 은동전이 20개 이상이면 룬다 **더블 루팅**을 켜고, 미만이면 끕니다.
- 두 재화가 모두 떨어지면 가방을 정리하고 캐릭터 선택 화면으로 나가 아직 돌 수 있는 **100레벨 캐릭터**로 바꿉니다. 모두 부족하면 가장 빨리 돌 수 있게 되는 캐릭터와 시각을 알려 주고 끝납니다.
- 캐릭터별로 마지막에 본 재화와 시각을 저장하고, **은동전 30분에 1개·마족 공물 12시간에 1개**씩 찬다고 보고 지금 돌 수 있는 캐릭터에만 접속합니다.
- **가방 정리**(캐릭터를 바꾸기 전): 자세히 가방 정리에서 상자 열기(패션 티켓 조각 보물 상자는 제외), 소모품 분해, 장비(무기·방어구·장신구) 전체 분해, 룬 분해(일반~에픽, 전설 이상은 남김).
- 가방 무게가 98%를 넘으면 **간단히 정리하기**로 장비 분해·재료 판매를 하고 계속합니다.
- 레벨업 다이스 알림은 가운데 X로 닫고, 심층 뒤 몰리 대화처럼 끼어드는 대화·장면은 넘기기를 누릅니다. 알림 창에 조작이 막히면 최대 3분까지 다시 시도합니다.

### 왜 룬다 일반 1-1, 페카 고분 심층 2-1인가

- **룬다 일반 1-1(은동전)**: 룬다는 1층에서 나오는 영혼석이 2층 것보다 비싸서 1층을 돕니다. 1층 중에서는 1-1이 가장 짧습니다.
- **페카 고분 심층 2-1(마족 공물)**: 페카 고분 심층 중 2-1이 가장 짧습니다.

같은 재화로 같은 보상을 받을 때는 짧은 구역이 시간당 효율이 가장 좋아서, 재화를 가장 빨리 소모할 수 있는 구역을 고정해 돕니다.

## 소스로 실행·빌드하기

Python 3.11(또는 3.12)이 필요합니다.

```powershell
python -m pip install -r .\workshop\requirements.txt
.\생활.bat
```

소스로 실행하면 「던전」 탭을 처음 열 때 `dungeon\.venv` 가상환경을 만들어 `dungeon\requirements.txt`(OpenCV·pywin32 등)를 설치하고, 매크로는 관리자 권한 별도 프로세스로 띄웁니다. `던전.bat`으로 콘솔에서 바로 실행할 수도 있습니다(`--check`, `--runs 2`, `--start runda|peka`, `--no-switch`, `--no-clean`, `--no-wings`).

`빌드.bat`을 실행하면 `dist\모비 통합 매크로\모비 통합 매크로.exe`가 만들어집니다(빌드용 가상환경은 `build\.venv`). 버튼 이미지는 `dungeon\templates\`에 있고, 게임 화면이 바뀌면 `dungeon\record.py`로 직접 플레이를 녹화해 다시 만듭니다.

```powershell
cd .\workshop
python -m unittest discover -v
```

## 파일과 개인 정보

| 내용 | exe | 소스 |
|---|---|---|
| 설정(목표·프리셋·CLI 경로·던전 옵션) | `data\workshop\settings.json` | `workshop\settings.json` |
| 실행 기록 | `data\workshop\logs\`, `data\dungeon\logs\` | `workshop\logs\`, `dungeon\logs\` |
| 캐릭터별 재화 기록 | `data\dungeon\characters.json` | `dungeon\characters.json` |
| 던전 녹화(화면 캡처) | `data\dungeon\recordings\` | `dungeon\recordings\` |

설정과 로그는 실행할 때 로컬에 만들어지며 Git에 포함되지 않습니다. 로그에는 CLI 요청·응답, 재고, 보관함 상태, 게임 화면이 남을 수 있으니 공유하기 전에 확인하세요. 이 저장소에는 게임 클라이언트나 CLI 실행 파일이 포함되지 않습니다.

레시피 데이터는 공개 자료와 CLI 이름·산출량을 연결한 것으로 게임 버전에 따라 다를 수 있습니다. 자세한 작업 순서·복구 방식은 [상세 설명](workshop/README.md)과 [스케줄링 점검표](workshop/SCHEDULING.md)를 참고하세요.
