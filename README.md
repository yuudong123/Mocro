# Mocro — 마비노기 모바일 생활·던전 도우미

- **생활 (`생활.bat`)**: 채집·가공·제작 목표를 입력하면 현재 가방과 보관함 재료, 시설 대기열을 확인해 작업 순서를 계획하는 Windows GUI입니다. 게임 조작에는 `MabinogiMobile_CLI.exe`만 사용하며 OCR이나 화면 좌표 클릭은 사용하지 않습니다.
- **던전 (에린 공방 「던전」 탭)**: 은동전으로 룬다 일반 1-1, 마족 공물로 페카 고분 심층 2-1을 반복합니다. CLI에 던전 명령이 없어서 상태 확인은 CLI로, 입장·재도전·이동은 화면 인식과 클릭으로 합니다. 아래 [던전 매크로](#던전-매크로)를 참고하세요.

> 개인 프로젝트입니다. 실제 게임의 레시피·CLI 동작은 업데이트로 바뀔 수 있습니다. 처음에는 소량으로 시험하고, 게임 이용 정책을 확인한 뒤 사용하세요.

## 준비

- Windows, Python 3.11 이상
- 마비노기 모바일 설치 및 게임 캐릭터 접속
- 게임 설치 폴더의 `MabinogiMobile_CLI.exe`

생활 도우미는 처음 한 번 PowerShell에서 이 폴더로 이동해 의존성을 설치합니다.

```powershell
python -m pip install -r .\workshop\requirements.txt
```

던전 매크로는 따로 준비할 필요가 없습니다. 에린 공방에서 「던전」 탭을 처음 열 때 `dungeon\.venv` 가상환경을 만들어 `dungeon\requirements.txt` 패키지(OpenCV·pywin32 등)를 설치합니다. 가상환경은 Python 3.11 또는 3.12로 만듭니다. `requirements.txt`가 바뀌면 다음에 탭을 열 때 다시 설치합니다. `던전.bat`으로 콘솔에서 바로 실행할 수도 있습니다.

### exe로 쓰기 (`모비 통합 매크로.exe`)

`빌드.bat`을 실행하면 `dist\모비 통합 매크로\모비 통합 매크로.exe`가 만들어집니다(폴더째 배포, 약 280MB). 공방과 던전 매크로, 필요한 패키지가 모두 들어 있어 Python이나 가상환경 없이 실행되고, 실행할 때 관리자 권한 확인 창이 한 번 뜹니다. 설정·로그·캐릭터 기록은 exe 옆 `data` 폴더에 저장됩니다. 빌드에는 Python 3.11 또는 3.12가 필요하고, 빌드용 가상환경은 `build\.venv`에 만듭니다. 키보드 감지(F12)와 화면 캡처 때문에 백신이 오탐할 수 있습니다.

기본 CLI 위치는 `C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe`입니다. 다른 위치에 설치했다면 실행 후 설정에서 CLI 경로를 변경하세요.

## 사용법

1. 게임에 캐릭터로 접속합니다.
2. `생활.bat`을 실행합니다.
3. 검색이나 시설별 목록에서 목표 품목을 선택하고 수량을 입력합니다. 텍스트로 `철괴 100, 강철괴 100`처럼 입력해도 됩니다.
4. 목표 수량에 이미 가방에 든 수량을 **포함할지** 선택합니다. 끄면 입력한 수량만큼 추가로 확보합니다.
5. 필요하면 설정에서 철괴처럼 원료 경로가 여러 개인 레시피의 기본값, 복구 방식, 날개 사용 한도를 고릅니다.
6. **시작**을 누릅니다. 자주 쓰는 목표는 프리셋으로 저장하면 다음에는 버튼 한 번으로 시작할 수 있습니다.

앱은 재고와 대기열을 다시 확인하면서 가능한 가공을 먼저 등록하고, 대기 중에는 부족한 재료를 채집하거나 제작합니다. 가공 시설은 가능한 범위에서 최대 7칸의 대기열을 활용합니다. 제작도 재료와 시설 상한이 허용하면 여러 회차를 묶어 요청합니다. 가방 무게가 90% 이상이면 채집을 멈추되 가능한 가공·제작·완성품 수령은 계속합니다.

중지 후 **이어하기**를 누르면 현재 재고와 대기열을 새로 읽고 남은 작업을 계산합니다. 이미 등록한 가공은 게임에서 계속 진행됩니다. 네트워크·게임 접속 문제로 `not_in_game`이 반환되면 주기적으로 재확인합니다.

## 던전 매크로

1. 게임 화면을 **800×600**으로 맞추고 캐릭터로 접속합니다. 게임이 관리자 권한으로 실행되므로 매크로도 관리자 권한을 요청합니다.
2. `생활.bat`으로 에린 공방을 열고 「던전」 탭에서 **시작**을 누릅니다(관리자 권한 확인 창이 뜹니다). 처음에는 **상태 확인**으로 조작 없이 인식 결과만 보거나 클리어 횟수 제한을 2처럼 걸어 시험하세요. 실행 기록과 캐릭터별 재화가 탭에 표시되고, **중지** 버튼이나 F12로 멈춥니다. 콘솔에서는 `던전.bat --check`, `던전.bat --runs 2`처럼 실행합니다.
3. 캐릭터가 있는 던전(안이나 입구)부터 돌고, 그 재화가 떨어지면 다른 던전으로 이동합니다. 은동전이 20개 이상이면 룬다 더블 루팅을 켜고, 20개 미만이면 끕니다. 두 재화가 모두 떨어지면 캐릭터 선택 화면으로 나가 아직 안 한 **100레벨 캐릭터**로 바꿔 계속하고, 100레벨 캐릭터를 모두 돌면 끝납니다(`--no-switch`로 끄기). 캐릭터별로 마지막에 본 은동전·마족 공물과 시각을 `dungeon/characters.json`에 저장하고, 은동전 30분에 1개·공물 12시간에 1개씩 찬다고 보고 지금 던전을 돌 수 있는 캐릭터만 접속합니다. 모두 부족하면 가장 빨리 가능해지는 캐릭터와 시각을 알려 주고 끝납니다. 캐릭터를 바꾸기 전(마지막 캐릭터는 끝내기 전)에는 자세히 가방 정리로 상자 열기(패션 티켓 조각 보물 상자 제외), 소모품 분해, 장비(무기·방어구·장신구) 전체 분해, 룬 분해(일반~에픽, 전설 이상은 남김)를 합니다(`--no-clean`으로 끄기). 재화 상자는 열지 않습니다. 가방 무게가 98%를 넘으면 가방의 **간단히 정리하기**로 장비 분해·재료 판매를 하고 계속합니다(무거운 재료·미스틱 다이스 항목은 끔). 정리해도 98% 아래로 내려가지 않으면 멈춥니다.
4. **F12**로 중지합니다. 클릭하는 동안 게임 창이 앞으로 나오고 마우스가 움직입니다.

던전 밖에서 시작할 던전을 정하려면 `--start runda` 또는 `--start peka`를 붙입니다. 다른 지역으로 이동할 때는 정령의 날개를 씁니다(`--no-wings`로 끄기). 문제가 생기면 멈추고 그때 화면을 `dungeon/logs/`에 저장합니다. 버튼 이미지는 `dungeon/templates/`에 있으며 게임 UI가 바뀌면 `dungeon/record.py`로 다시 녹화해 갱신합니다.

## 파일과 개인 정보

- 실행 파일: `생활.bat`, `던전.bat`
- 프로그램·레시피·시설 데이터: `workshop/`
- 개인 목표·프리셋·CLI 경로: `workshop/settings.json`
- 자세한 실행 기록: `workshop/logs/`, `dungeon/logs/`
- 던전 녹화(화면 캡처 포함): `dungeon/recordings/`
- 캐릭터별 재화 기록: `dungeon/characters.json`

설정과 로그는 실행 시 로컬에 만들어지며 Git에 포함되지 않습니다. 로그에는 CLI 요청·응답, 재고, 보관함 상태 등이 기록되므로 문제 제보 시 공유 전에 내용을 확인하세요. 이 저장소에는 게임 클라이언트나 CLI 실행 파일이 포함되지 않습니다.

## 검증과 한계

```powershell
cd .\workshop
python -m unittest discover -v
```

레시피 데이터는 공개 자료와 CLI 이름·산출량을 연결한 것입니다. 일부 레시피는 게임 버전에 따라 다를 수 있으며, 재료 정보가 불완전한 품목은 안전하게 소량씩 진행할 수 있습니다. 실제 게임 재화를 쓰는 전체 자동 완주까지 보증하지는 않습니다.
